One joke about Monday mornings for make.fun's "Monday Morning Punchlines" bounty. The program writes the punchline to `/output/entry.txt`.

> My alarm went off this morning and apologized — even it didn't want to be the one to tell me it's Monday.

Why this line: the alarm is the one thing that is supposed to be on Monday's side, and even it is sorry — the dread gets a turn nobody expects, in one sentence, with no setup wasted.

## Run it

```sh
python3 main.py
```

It writes the single-line punchline (no trailing newline) to `/output/entry.txt`, then reads it back and verifies the gate (1–200 characters, one non-blank line) before exiting.
